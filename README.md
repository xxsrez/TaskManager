# Task Manager

Task Manager — компактная система управления работой, вдохновлённая Linear.
Продукт сосредоточен на задачах, проектах, релизах, сохранённых представлениях
и Kanban-досках без организационной сложности полноценного трекера.

Сейчас репозиторий находится на стадии проектирования: приложение ещё не
реализовано, а технологический стек не выбран.
